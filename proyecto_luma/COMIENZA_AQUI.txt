LUMA STORE - ENTREGA CON POSTGRESQL
===================================

1. Abre server/README.md para instalar la tienda, la base y el emulador.
2. Ejecuta npm.cmd --prefix server run db:setup para aplicar las migraciones.
3. Inicia los tres servicios de la guia y abre http://localhost:4201.
4. Abre docs/13_PRESENTACION_Y_EVIDENCIAS.md para preparar la exposicion.

El README principal enlaza a la publicacion alternativa con Firestore.
La demostracion con PostgreSQL usa cuentas, pagos y entregas ficticios.
